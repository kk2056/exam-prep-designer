## 30 秒看懂

你不是让 AI 帮你出几道题。你要的是**一套能直接拿来备考的资料**。

```
考试名  →  考试画像  →  知识点地图  →  复习资料  →  专项练习
                                                      ↓
                            打印交付  ←  A4排版  ←  答案校验  ←  模拟卷
```

十步全自动。你只说一句「2026年12月四级，给我一套打印版模拟卷」，剩下的它自己跑完。

## 适配任何考试

🔴 **流程跟考试种类无关。** 十步是固定的，变的是内容——考试画像、知识点、题型、练习、试卷全部随考试自动切换。

| 类别 | 举例 | 知识点地图长这样 | 练习长这样 |
|---|---|---|---|
| **语言类** | 四六级、考研英语、雅思托福、日语 N1 | 词汇 / 语法 / 题型技巧 | 阅读、听力、写作、翻译 |
| **公职类** | 国考、省考、事业单位 | 行测模块 / 申论题型 / 时政 | 言语、判断、数资、申论 |
| **计算机类** | 计算机等级、软考、各类技术认证 | 概念 / API / 命令 / 算法 | 选择、读程序、操作、编程 |
| **财经类** | CPA、初级会计、税务师、CFA | 准则 / 分录 / 计算公式 | 计算、案例分析 |
| **法律类** | 法考、法律职业资格 | 法条 / 司法解释 / 判例规则 | 案例、论述 |
| **资格类** | 教资、医师资格、建造师 | 大纲考点 / 法规 / 实务 | 选择、简答、案例 |
| **学业类** | 中考、高考、期末、考研专业课 | 章节考点 / 公式 / 题型 | 选择、填空、解答 |

**同一套流程，跑三种毫不相关的考试：**

| | 英语四级 | 计算机二级 Python | 国考行测 |
|---|---|---|---|
| P0 考点 | 阅读同义替换 | 列表字典切片 | 资料分析速算 |
| 练习形态 | 篇章阅读 | 读程序写结果 | 单题限时 |
| 模拟卷 | 写作→听力→阅读→翻译 | 选择→操作→编程 | 五大模块连打 |

不挑考试，也不预设形态——拿到考试名先建画像，再决定知识点和题型长什么样。

## 你会拿到什么

跑一次完整流程，八样东西：

| # | 产出 | 内容 |
|---|---|---|
| 1 | **考试画像** | 结构 / 题型 / 分值 / 时间 / 能力要求 / 你的目标 |
| 2 | **高频考点** | 每个考点：为什么重要 / 常见考法 / 解题方法 / 陷阱 / 示例 |
| 3 | **重点复习清单** | 「考前最值得掌握的 20 / 50 / 100 个内容」 |
| 4 | **专项练习** | 按模块出题，难度贴近真实考试 |
| 5 | **完整模拟卷** | 对齐官方题型、题量、时间、分值 |
| 6 | **参考答案** | 单独一栏 |
| 7 | **答案解析** | 正确答案 / 核心原因 / 错项为什么错 / 对应知识点 |
| 8 | **推荐学习顺序** | 从最值得学到最不值得学 |

**要打印的话**：A4 排版，试卷版 / 答案版 / 解析版三份分离，答题区按题型预留。

## 有它 vs 没它

| | 没它 | 有它 |
|---|---|---|
| 给什么 | 几道零散的题 | 一套完整备考资料包 |
| 考点优先级 | 一股脑全塞给你 | P0 必考 → P3 低频，排出优先级 |
| 答案可信度 | 生成完就给你，可能有错 | **强制二次校验**才交付 |
| 出题质量 | 选项长短不一、有歧义 | 8 项质量标准 + 8 项答案复核 |
| 数据真实性 | 编造"高频" | 没依据就明说「这是趋势判断，不是统计结果」 |
| 打印 | 密密麻麻一坨 | A4、分页、答题区、页码齐全 |

## 怎么用

**说人话就行，不用填表。**

```
「我 2026 年 12 月考四级，目标 500，阅读最差，帮我做一套备考资料」
「国考行测，11月底考，帮我出一套模拟卷，按真实考试时间」
「计算机二级 Python，下个月考，给我出几套操作题练练」
「CPA 会计，长投和合并报表最头疼，帮我整理」
「教资笔试，一个月，帮我押一下重点」
```

**唯一必须回答的问题：考哪个试。** 其他全部走默认值，不追问。

| 缺什么 | 默认值 |
|---|---|
| 考试时间 | 按你提供的信息推断 |
| 目标分数 | 该考试常规及格线 |
| 当前水平 | 未知 |
| 难度 | 接近真实考试 |
| 输出格式 | 适合打印的 A4 文档 |

## 三条硬底线

| | |
|---|---|
| 🔴 **答案强制二次校验** | 不允许相信第一次生成的答案。逐题查 8 项，发现问题改题重判，通过才交付 |
| 🔴 **不伪造统计数据** | 「高频」必须有依据。资料不够就明说「以下为趋势判断，而非严格统计结果」 |
| 🔴 **不复制受版权真题** | 可以模拟题型、难度、主题、考察规律，但题目、文章、选项必须原创 |

还有一条信任规则：使用外部信息时，严格区分**官方事实 / 历史统计 / 第三方分析 / AI 推断**四级。🔴 禁止把推测包装成官方结论，不确定的就标「不确定」。

## 知识点优先级

不是所有考点都值得花同样的时间。每个知识点按 **重要性 × 出现频率 × 学习难度** 排序，分四级：

| 级别 | 含义 | 怎么处理 |
|---|---|---|
| **P0** | 核心必考 | 必须吃透，优先练 |
| **P1** | 高频重点 | 重点练 |
| **P2** | 常见考点 | 常规练 |
| **P3** | 低频拓展 | 有余力再练 |

最终给你一张「从最值得学到最不值得学」的清单。

---

## 它会按你的水平调整

提供目标分数 / 当前成绩 / 薄弱模块 / 每天学习时间 / 距考试天数后，自动调整知识点优先级、题目难度、练习数量、模拟频率、复习顺序。

| 基础 | 路径 |
|---|---|
| 低基础 | 基础知识 → 高频考点 → 简单练习 → 中等练习 → 模拟考试 |
| 高基础 | 错题诊断 → 高频难点 → 中高难度训练 → 限时模拟 → 冲刺训练 |
