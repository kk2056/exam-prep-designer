# 输入示例：任何考试都这么说

> 这个 skill **不挑考试**。下面是各类考试的真实说法，处理方式完全一样。

---

## 语言类

> 「我 2026 年 12 月考四级，目标 500，现在大概 380，阅读最差，每天能学 2 小时，帮我做一套备考资料」
> 「2026年12月四级，给我做一套打印版模拟卷」
> 「整理一下考研英语的高频考点」
> 「雅思口语怎么准备」

**走的路**：词汇 / 语法 / 题型技巧 → 听说读写分模块练习 → 完整卷。

---

## 公职类

> 「国考行测，11月底考，帮我出一套模拟卷，按真实考试时间」
> 「省考申论，我不知道怎么练，给我整理高频题型」
> 「事业单位考试，每天 3 小时，帮我排一下复习顺序」

**走的路**：行测五大模块 / 申论题型 → 单题限时训练 + 套卷连打 → 申论范文与批改要点。

---

## 计算机类

> 「计算机二级 Python，下个月考，给我出几套操作题练练」
> 「软考中级，帮我整理高频考点」
> 「我要考 AWS 认证，帮我做练习题」

**走的路**：概念 / API / 命令 / 算法 → 选择 + 读程序写结果 + 操作题 → 模拟卷。

---

## 财经类

> 「CPA 会计，明年考，长投和合并报表最头疼，帮我整理」
> 「初级会计，两个月，给我出模拟卷」
> 「税务师，帮我排复习优先级」

**走的路**：准则 / 分录 / 计算公式 → 计算题 + 案例分析 → 模拟卷。

---

## 法律类

> 「法考，客观题，帮我整理高频法条」
> 「法考主观题怎么练」

**走的路**：法条 / 司法解释 / 判例规则 → 案例题 + 论述题 → 模拟卷。

---

## 资格 / 学业类

> 「教资笔试，一个月，帮我押一下重点」
> 「期末考，数据结构，给我出套卷子练练」
> 「高考数学，我 110 分水平想冲 130」

**走的路**：大纲考点 / 公式 / 题型 → 分模块练习 → 模拟卷。

---

## 唯一必须问的情况

> 「帮我做一套复习资料」

🔴 考试名都没有 → 这是**唯一必须提问**的场景。一次只问一句：「你想准备哪个考试？」

---

## 一句话原则

**流程固定十步，内容随考试而变。用户说得越少，你推断得越多；只有考试名这一项，必须问。**
