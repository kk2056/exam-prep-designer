# 输出示例：同一套流程，三种不同的考试

> 🔴 **核心看点：十步流程完全一样，变的只有内容。**
> 下面用「英语四级 / 计算机二级 Python / 国考行测」三种毫不相关的考试做对照。

---

## 一、流程通用性的对照

| STEP | 英语四级 | 计算机二级 Python | 国考行测 |
|---|---|---|---|
| 1 考试画像 | 写作/听力/阅读/翻译 | 选择/操作/编程 | 五大模块 135 题 120 分钟 |
| 3 知识点地图 | 听力主旨·阅读同义替换·写作结构 | 数据结构·算法复杂度·标准库 | 言语·判断·数资·常识 |
| 4 高频词条 | 高频词汇 + 搭配 | 核心 API + 标准库函数 | 高频成语 + 速算公式 |
| 5 专项练习 | 篇章阅读 + 选项 | 读程序写结果 + 操作题 | 单题限时训练 |
| 6 模拟卷 | 写作→听力→阅读→翻译 | 选择→操作→编程 | 模块连打，严格计时 |

**流程一模一样，产出完全不同。**

## 三、专项练习（三种考试各一题，看字段完全一致）

### 英语四级 · 阅读

```
QUESTION         The word "undermine" in Paragraph 3 is closest in meaning to ______.
OPTIONS          A) weaken    B) support    C) overlook    D) accelerate
CORRECT_ANSWER   A
EXPLANATION      undermine = 逐渐削弱。support 是反义陷阱，overlook/accelerate 语义不搭。
KNOWLEDGE_POINT  阅读·词义猜测
DIFFICULTY       中
```

### 计算机二级 Python · 读程序写结果

```
QUESTION         以下代码的输出结果是？
                 s = "Python"
                 print(s[1:4] + s[-2:])
OPTIONS          A) ython   B) ythonon   C) ytho   D) ythonon
CORRECT_ANSWER   （校验后修订，见下节）
EXPLANATION      s[1:4]="yth"，s[-2:]="on"，拼接为 "ython"。
KNOWLEDGE_POINT  字符串切片与索引
DIFFICULTY       中
```

### 国考行测 · 资料分析

```
QUESTION         2025 年该省 GDP 约为 4.8 万亿元，同比增长 6.2%，则 2024 年约为多少万亿元？
OPTIONS          A) 4.32   B) 4.52   C) 4.68   D) 5.10
CORRECT_ANSWER   B
EXPLANATION      4.8 ÷ 1.062 ≈ 4.52。A 项错按减少 6.2% 计算，D 项是反向误用增长率。
KNOWLEDGE_POINT  资料分析·基期量计算
DIFFICULTY       中
```

## 四、STEP 7 答案校验（这三种考试都会翻车）

| 题号 | 考试 | 初稿答案 | 校验结果 | 处理 |
|---|---|---|---|---|
| 1 | 四级阅读 | A | ✅ 通过 | — |
| 2 | 计算机二级 | D | ❌ **选项 B 与 D 重复** | **重出选项**，四个选项各不相同后重判 |
| 3 | 行测资料分析 | B | ✅ 通过 | — |
| 4 | 行测言语 | C | ⚠️ 题干有歧义 | **改题干**，加限定词后重判 |

> **初稿 4 题里 2 题有问题。** 这就是 STEP 7 不交付初稿的原因——它跟考试种类无关，任何卷子都适用。

## 五、STEP 8 答案与解析（分离输出）

```
【参考答案】
1. A    2.（重出选项后确定）    3. B    4.（改题后确定）
```

**解析模板（三种考试共用）**：

- **正确答案**
- **核心原因**
- **错误选项为什么错**
- **对应知识点**

🔴 解析要帮助理解，不要把一道选择题写成博士论文。

## 六、STEP 9 打印排版（按题型自适应）

| 题型 | 预留空间 | 适用考试 |
|---|---|---|
| 选择题 | 适当留白 | 通用 |
| 填空题 | 预留横线 | 计算机/学业 |

| 简答题 | 预留多行 | 资格类 |
