# 十步执行规范（工作台版）

`SKILL.md` 是行为指令，这份是执行细节：每步的**输入 / 动作 / 输出模板 / 检查点 / 常见坑**。

---

## STEP 1 · 建立考试画像

**输入**：考试名称（必填）+ 用户零散信息
**动作**：查官方最新结构 → 填 `EXAM_PROFILE` → 信息不确定处标注
**输出模板**：

```
EXAM_PROFILE
├── exam_name        考试名称
├── exam_date        考试时间
├── sections         科目/模块（含顺序）
├── question_types   题型清单
├── score_distribution  各题型分值
├── time_distribution   各模块建议用时
├── difficulty       难度定位
├── key_abilities    能力要求
└── user_target      用户目标分数
```

**检查点**：10 项是否齐全？分值加起来是否等于总分？
**常见坑**：凭记忆写考试结构。🔴 规则可能变，必须查最新官方信息；查不到就标「不确定」。

---

## STEP 2 · 历史资料分析

**输入**：近年真题 / 用户提供的资料 / 联网检索结果
**动作**：抽取高频规律 → 转成结构化，不罗列原文
**分析 10 项**：

高频知识点 · 高频词汇 · 高频语法 · 高频题型 · 高频主题 · 常见错误 · 题目难度 · 题型比例 · 命题趋势 · 能力要求变化

**检查点**：每条「高频」是否有依据？
**常见坑**：🔴 资料不够时编造统计数字。必须写明「以下为基于现有资料的趋势判断，而非严格统计结果。」

---

## STEP 3 · 建立知识点地图

**输入**：STEP 2 结果
**动作**：按 **重要性 × 出现频率 × 学习难度** 排序
**输出模板**：

```
知识点 → 出现频率 → 所属题型 → 难度 → 重要程度 → 推荐练习量
```

**重要程度四级**：

| 级别 | 含义 | 处理方式 |
|---|---|---|
| P0 | 核心必考 / 高优先级 | 必须吃透，优先练 |
| P1 | 高频重点 | 重点练 |
| P2 | 常见考点 | 常规练 |
| P3 | 低频拓展 | 有余力再练 |

**必须包含的 7 类**：核心知识点 / 高频知识点 / 易错知识点 / 高频题型 / 高频主题 / 能力薄弱点 / 推荐练习顺序

**检查点**：最终是否形成「从最值得学到最不值得学」的清单一句话结论？

---

## STEP 4 · 生成复习资料

### A. 高频考点（每个含 6 项）

考点名称 / 为什么重要 / 常见考法 / 解题方法 / 常见陷阱 / 示例

🔴 不要写成百科全书，只给真正可能用到的。

### B. 高频词汇或知识点（按考试类型决定生不生成）

内容 / 中文解释 / 常见用法 / 高频搭配 / 示例 / 记忆提示

### C. 重点复习清单

「考前最值得优先掌握的 **20 / 50 / 100** 个内容」——按考试规模自动决定数量。

---

## STEP 5 · 生成专项练习

**每道题的 6 个内部字段**（缺一不可）：

```
QUESTION          题干
OPTIONS           选项
CORRECT_ANSWER    正确答案
EXPLANATION       解析
KNOWLEDGE_POINT   考察的知识点
DIFFICULTY        难度
```

**出题 8 条质量标准**：

- 题型符合真实考试
- 难度接近真实考试
- 覆盖高频知识点
- 不重复
- 干扰项合理
- 避免明显的错误答案
- 避免歧义题
- 🔴 避免「只有一个选项明显比别的长/短」这类低质量特征

---

## STEP 6 · 生成完整模拟试卷

**必须对齐 6 项**：官方题型结构 / 官方题量 / 官方时间 / 官方分值比例 / 难度 / 语言风格

🔴 **版权红线**：不得直接复制受版权保护的完整真题。

**允许**：根据真题考察规律重新原创、模拟题型、模拟难度、模拟主题、模拟能力要求。
**必须原创**：题目、文章、选项。

---

## STEP 7 · 答案独立校验（强制）

生成完所有题目后，**不信任第一次生成的答案**，逐题走 8 项检查：

| # | 检查项 |
|---|---|
| 1 | 正确答案是否真的正确 |
| 2 | 是否存在两个正确答案 |
| 3 | 是否不存在正确答案 |
| 4 | 题干是否有歧义 |
| 5 | 选项是否合理 |
| 6 | 答案与解析是否一致 |
| 7 | 题目是否真正考察指定知识点 |
| 8 | 难度是否合理 |

**发现问题 → 修改题目 → 重新判断答案 → 再次验证**，直到通过。

🔴 这一步不能省。交初稿 = 不合格。

---

## STEP 8 · 生成答案与解析

**参考答案**：单独一栏，只列题号+选项
**答案解析**（每题 4 项）：正确答案 / 核心原因 / 错误选项为什么错 / 对应知识点

🔴 解析要帮助理解，不要把一道选择题写成博士论文。

---

## STEP 9 · 可打印排版

**默认 10 项**：A4 / 清晰标题 / 合理页边距 / 统一字体 / 清晰题号 / 足够行距 / 合理分页 / 页码 / 答题区 / 姓名·学号·日期栏

🔴 不要为了省页面把内容挤成一团。

**按题型预留答题空间**：

| 题型 | 预留 |
|---|---|
| 选择题 | 适当留白 |
| 翻译题 | 预留书写区域 |
| 作文 | 预留足够横线 |
| 简答题 | 预留多行 |
| 听力题 | 保留必要记录区域 |

**三份分离**：① 试卷版 ② 答案版 ③ 解析版
🔴 答案与试卷必须分开。

---

## STEP 10 · 输出资料包

| 用户说 | 输出 |
|---|---|
| 「帮我准备考试」 | 完整包 8 项：考试画像 / 高频考点 / 重点清单 / 专项练习 / 模拟卷 / 答案 / 解析 / 推荐学习顺序 |
| 「给我一套模拟卷」 | 直接给卷子，不输出大段理论 |
| 「我要打印」 | 优先打印版文档 |

---

## 个性化调整

拿到**目标分数 / 当前成绩 / 薄弱模块 / 每天学习时间 / 距考试天数**后，自动调整：知识点优先级 · 题目难度 · 练习数量 · 模拟频率 · 复习顺序。

| 基础 | 路径 |
|---|---|
| 低基础 | 基础知识 → 高频考点 → 简单练习 → 中等练习 → 模拟考试 |
| 高基础 | 错题诊断 → 高频难点 → 中高难度训练 → 限时模拟 → 冲刺训练 |

---

## 交付前双检

**CONTENT_CHECK**：符合考试结构 / 覆盖核心题型 / 覆盖重点知识 / 无事实错误 / 无答案错误 / 无重复题 / 无歧义题 / 无明显 AI 痕迹 / 符合用户目标

**DOCUMENT_CHECK**：A4 合理 / 无大面积空白 / 无文字拥挤 / 题目未被错误分页 / 答题区足够 / 答案与试卷分离 / 页码正确 / 标题层级清晰

---

## 信息来源四级标注

使用外部资料时必须区分，🔴 禁止把推测包装成官方结论：

1. **官方事实** — 来自官方渠道
2. **历史统计** — 有数据的统计结果
3. **第三方分析** — 机构/老师观点
4. **AI 推断** — 模型自己的判断

无法确认 → 明确标注「不确定」。
